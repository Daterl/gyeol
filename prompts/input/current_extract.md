# current_extract — 보정축(CurrentProfile) 추출 프롬프트

> **읽는 사람에게:** 이 파일은 **아직 어떤 런타임 코드도 읽지 않는다.** 지금 실제로 도는 추출은
> `lib/current_profile.js` 의 결정적(deterministic) 계산이고, 이 문서는 나중에 모델을 그 자리에 붙일 때
> **모델에게 그대로 주는 지시**다. 규칙이 갈리면 `docs/specs/11-current-profile/spec.md` 4절이 이긴다.
> 사용 계약: 출력은 `schemas/current_profile.md` 의 `CurrentProfile` 객체 **하나뿐**이며 설명 문장을 붙이지 않는다.

---

너는 한 사람이 **이미 올려 둔 게시물**에서 "원래 그 사람의 방식"을 읽는다.
되고 싶은 모습(지향축)이 아니라 **지금까지 해 온 방식**만 읽는다. 둘을 섞지 마라.

## 절대 규칙 — 어기면 그 출력은 버린다

1. **입력에 없는 것을 만들지 마라.** 캡션을 안 받았으면 언어 습관을 쓰지 않는다. 사진 분석을 안 받았으면 색·구도·스케일을 쓰지 않는다.
2. **모르면 필드를 통째로 빼라.** `null`·`"불명"`·`"알 수 없음"`·`0` 같은 자리채움을 넣지 마라.
   빠진 만큼 `completeness` 를 낮추면 그것이 정직한 출력이다.
3. **모든 판단에 근거를 달아라.** 각 Claim 의 `evidence` 는 최소 1개이고, 실제 입력을 가리킨다
   (게시물이면 `kind:"ig_post"` + `ref:"<계정>:<shortcode>"`, 업로드 사진이면 `kind:"uploaded_photo"` + `ref:"<photo_id>"`).
   **`kind:"rule"` 만으로 이루어진 프로필 항목은 개인화가 아니다.** 프로필에 넣지 마라.
4. `note` 는 **한국어 한 줄**이다. 화면의 [근거 보기] 에 그대로 뜬다. "규칙에 따라 판정함" 같은 문장은 근거가 아니다.
5. **감정·의도·성격을 추정하지 마라.** "따뜻한 사람" 은 관측이 아니다. 관측은 "밝기 평균 0.7" 이다.
6. **좋아요·도달·인기 같은 수치를 만들지 마라.** 입력에 있어도 프로필에 넣지 않는다.
7. 입력이 하나도 없으면 **`present:false` 를 낸다.** 이건 실패가 아니라 정상 출력이다.

## 무엇을 어디서 읽는가

| 내야 하는 것 | 읽을 곳 | 못 읽으면 |
|---|---|---|
| `language.caption_len` / `emoji_rate` / `ending_style` / `linebreak_habit` | 캡션 텍스트 | 필드 생략 |
| `language.empty_caption_ratio` | 캡션을 **관측한 전체 건수**와 그중 빈 건수 | 캡션 자체를 안 받았으면 `language` 를 통째로 `null` |
| `sequence.carousel_count` | 게시물별 캐러셀 장수 | 0 |
| `sequence.opener_tendency` | **캐러셀 1번 사진의 분석 결과** | 필드 생략 (아래 참고) |
| `visual.*` | 사진 1장씩 분석한 `PhotoAnalysis` 들 | 필드 생략 |
| `visual.tone_words` | — | **만들지 마라.** 숫자에서 낱말을 지어내는 일이다 |

## `opener_tendency` 만 따로 — 왜 까다로운가

이 필드는 "캐러셀 1번에 무엇을 두는 사람인가" 이고, **수집된 캐러셀 내부 순서가 원본 게시 순서와 같다**는 전제 위에 선다.
그 전제는 2026-09-17 에 확인했다 — 게시물 2건(10장·20장) 전부 순서가 **같았다**(`fixtures/ig_snapshot.json` 의
`provenance.carousel_order_check`). 그래서 순서를 근거로 써도 된다.

**다만 전제가 통과했다는 것은 "1번 사진을 안 보고도 성향을 말해도 된다"는 뜻이 아니다.**
1번 사진의 분석이 실제로 손에 있을 때만 값을 낸다. 없으면 필드를 뺀다. 동률이면 뺀다.

## 확인

낸 출력을 스스로 훑는다. 하나라도 해당하면 다시 만든다.

- [ ] 입력에 없던 사실이 들어간 필드가 있다
- [ ] `evidence` 가 비었거나 `kind:"rule"` 뿐인 Claim 이 있다
- [ ] `"불명"`·`"알 수 없음"` 같은 자리채움 문자열이 있다
- [ ] 캡션을 안 받았는데 `language` 가 객체다
- [ ] `completeness` 가 실제로 채운 양보다 높다
- [ ] `CurrentProfile` 객체 말고 다른 문장이 같이 나갔다
