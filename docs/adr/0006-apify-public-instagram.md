# ADR-0006: Apify Instagram Scraper와 공개 계정만 사용

- 날짜: 2026-09-18
- 상태: 확정 — diego.yoon의 명시적 결정. 연동 구현·실수집 검증은 별도
- 결정자: **diego.yoon** (`@jangwonyoon`) / 협업: **enzo.cho** (`@onejaejae`)
- 관련: [확장 엄브렐라 #65](https://github.com/Daterl/gyeol/issues/65), [리서치](../research/instagram-product-review-2026-09-18.md), [HTML 기획](../plans/instagram-product-expansion.html)

## 배경

기존 기획은 Apify를 수집 후보로 두고 비공개 계정의 대체 경로도 함께 설명했다. 사용자가 “이거를 사용해서 보기로했고 비공개 계정은 확인안하기로 했어”라고 정정했다. 제공자의 기술적 제한과 별개로 제품의 수집 범위를 명확히 고정한다.

## 결정

1. Instagram 수집에는 **[Apify Instagram Scraper](https://apify.com/apify/instagram-scraper), Actor `apify/instagram-scraper`**를 사용한다. 유사한 이름의 Post Scraper나 다른 제공자를 같은 결정으로 취급하지 않는다.
2. 본인 계정과 참고 계정 모두 **공개 계정·공개 게시물만** 조회·수집·분석 대상으로 삼는다. 비공개로 확인된 계정은 지원 범위 밖이라고 안내하고 콘텐츠 수집을 진행하지 않는다. 비공개 계정에 표시된 공동 작성 게시물을 우회 수집하는 예외도 만들지 않는다.
3. 수집 실패만으로 비공개라고 단정하지 않는다. 공개 여부가 불명확하거나 접근이 제한되면 미확인/접근 불가로 표시한다. 비공개 콘텐츠를 읽기 위한 로그인·팔로우 요청·쿠키/세션 전달·다른 수집 경로로의 우회는 제품에 넣지 않는다.
4. 사용자가 직접 사진·설명을 넣는 경로는 공개 프로필 연결 뒤의 큐레이션 입력으로 유지한다. 이는 사용자가 제공한 자료의 분석이며 **비공개 계정을 조회한 결과가 아니다.** 아이덴티티 없이 시작하는 과거 경로는 ADR-0008이 대체한다.
5. 제공자 선정과 실제 수집 성공은 구분한다. 공개 게시물 표본으로 캐러셀 순서·미디어 유형·캡션·장소·태그·공동 작성 정보의 반환 여부를 검증한다. 음악·스토리·하이라이트의 필드 완전성은 별도 확인하며 누락을 “없음”으로 만들지 않는다.

## 기존 결정과의 관계

- [ADR-0008](0008-public-profile-curation-and-sharing.md)은 공개 프로필 연결을 첫 필수 단계로 삼고, 이 ADR의 수집 범위를 유지한다. 사진만으로 시작하는 이전 경로는 더 이상 적용하지 않는다.
- Apify 연결은 계정 존재와 공개 자료를 확인할 뿐 소유권 인증이 아니다. 화면에는 `인증 완료` 대신 `공개 프로필 연결 완료`와 `본인 소유 여부는 확인하지 않았어요`를 표시한다.
- `docs/intent.md` C1의 제출용 스냅샷 경로는 유지한다. 수집 도구 확정이 라이브 연동 완료나 제출 필수 범위 변경을 뜻하지 않는다. C7 공식 API/OAuth 연동은 이번 수집 경로에 추가하지 않는다.
- 브라우저에서 사용자가 로그인해 사례를 열람한 것은 리서치다. GYEOL 서버가 사용자의 로그인 세션을 사용하는 설계의 근거가 아니다.
- 사람마다, 같은 사람도 상황마다 취향과 문체가 다르다. 사용자 선택 참고 게시물과 이번 의도를 우선하며, 특정 계정 사례를 모든 사용자의 기본값으로 삼지 않는다.

## 반영과 확인

- enzo.cho: 지정 Actor 연동과 공개 자료의 입력 이해. diego.yoon: 공개 범위 안내·선택·실패 상태·출력과 배포. 공유 계약은 공동 확인한다.
- 비공개 제외 동작은 고정 응답/fixture로 확인하며 비공개 계정을 실수집하는 검증을 계획하지 않는다.
- 직접 업로드한 자료와 Apify 수집 자료의 출처가 구분되고, 부분 성공·누락·사용자 편집이 보존돼야 한다.
- 이 문서 작업에서는 제품 코드·키·외부 호출을 변경하지 않는다. 실제 연동의 비용·환경·필드 검증은 #65에 남긴다.
