# ADR-0001: 한 화면 입력과 사진만으로 시작하기

- 날짜: 2026-09-17
- 상태: 대체됨 — 2026-09-18 [ADR-0008](0008-public-profile-curation-and-sharing.md)이 공개 프로필 연결 필수와 사진 3~15장으로 변경
- 결정자 / 화면·출력 생성 담당: **diego.yoon** (`@jangwonyoon`)
- 협업자 / 입력 이해 담당: **enzo.cho** (`@onejaejae`)
- 관련: [개발 범위](../intent.md), [#14 입력 화면](https://github.com/Daterl/gyeol/issues/14), [#15 결과 화면](https://github.com/Daterl/gyeol/issues/15), [PR #21 계약 초안](https://github.com/Daterl/gyeol/pull/21)

> 이 문서는 초기 결정을 보존한다. 현재 제품 계약은 [ADR-0008](0008-public-profile-curation-and-sharing.md)을 따른다. 공개 프로필 연결 없이 사진만으로 시작하는 경로와 3~20장 범위는 더 이상 적용하지 않는다.

## 배경

`gyeol-plan.html`과 `gyeol-prototype.html`은 한 화면에서 입력을 받지만, #14는 사진과 아이덴티티 입력을 두 단계로 나눈다. 프로토타입은 아이덴티티 입력이 전부 비어 있으면 진행을 막지만, #14는 건너뛰기를 허용한다.

2026-09-17 그릴링에서 diego.yoon이 두 질문 모두 추천안을 선택했다. 이 ADR은 두 충돌 지점의 제품 동작을 확정한다.

## 결정

### 1. 입력은 한 화면에서 받는다

- 올릴 사진 입력을 화면 맨 위에 크게 둔다.
- 그 아래에 내 인스타그램 URL, 비공개 계정용 기존 게시물 업로드, 레퍼런스 인스타그램 URL, 원하는 느낌 입력을 둔다.
- 아이덴티티 입력은 선택이다. 필수 표시나 별도의 두 번째 단계로 진행을 강제하지 않는다.
- 기존 HTML의 화면 구조를 재사용한다. 레퍼런스 사진 업로드 등 개발 범위에서 제외한 경로를 추가하지 않는다.

### 2. 사진만으로 결과를 받을 수 있다

- 올릴 사진 3~20장이 있으면 아이덴티티를 전부 비워도 진행할 수 있다.
- 사진에서 확인한 특성을 근거로 순서를 제안한다. 제공되지 않은 취향이나 과거 게시 습관을 추정해 사실처럼 설명하지 않는다.
- 결과에 개인화 정보 없이 만든 제안임을 표시한다. 사진만 넣은 사용자에게 지향이나 기존 피드를 읽었다고 설명하지 않는다.
- 순서 근거, 타이틀, 캡션의 채움·비움, 사용자 편집은 기존 제품 범위를 유지한다. 캡션은 사진에서 확인한 사실 안에서만 작성한다.

## 협업과 반영 범위

| 담당 | 반영할 내용 |
|---|---|
| diego.yoon | #14 spec에 한 화면 입력과 사진만으로 진행하는 경로 반영. #15에서 해당 결과의 안내 문구와 근거 표시 구현 |
| enzo.cho와 협업 | 아이덴티티 없는 요청의 입력 표현, 사진 기반 제안, `OrderedFeed`와 mock의 대응 방식 확인 |
| 공동 계약 확인 | 현재 프로필이 없을 때 `present:false`, `current_profile_id:null`, `disclosure:"target_only"` 정합성 유지. 사진만 입력된 경우의 TargetProfile 구성과 UI 안내 연결은 계약에 명시 |

`target_only`는 기존 계약 값이며, 사진만 입력된 화면에서 반드시 “지향을 반영했다”는 문구를 써야 한다는 뜻은 아니다. 계약 변경이 필요하면 양쪽 담당자가 확인한다.

이 ADR은 diego.yoon의 제품 결정을 기록한다. enzo.cho의 승인, #1 스키마 합의, PR merge 또는 구현 완료를 의미하지 않는다. GitHub 이슈 본문과 PR #21은 이 문서 작성으로 변경되지 않는다.

## 확인 기준

- 사진과 아이덴티티 입력이 한 화면에 있고 사진이 먼저 보인다.
- 사진 3장과 20장 각각에서 아이덴티티를 모두 비운 채 결과까지 진행할 수 있다. 3장 미만으로는 진행하지 않는다.
- 사진만 입력한 결과에는 개인화 정보가 없었다는 안내와 사진에 근거한 순서 설명이 있다.
- 아이덴티티가 없는데 기존 게시물의 습관이나 사용자의 취향을 읽었다는 문구가 없다.
- 아이덴티티를 제공하는 기존 경로도 사용할 수 있다.
