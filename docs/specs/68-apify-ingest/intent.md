# 의도

공개 인스타그램 URL이 준비된 계정 목록 밖에 있다는 이유로 분석에서 끊기는 문제를 해소한다.
수집된 게시물에서 관측한 언어만 현재·지향 프로필에 전달하는 것이 목적이다.
라이브 수집은 선택 기능이며 사진만 입력과 사전 스냅샷 데모는 그대로 동작해야 한다.
게시물 ID와 출처가 없으면 프로필 판단을 원본으로 되짚을 수 없으므로 수집부터 근거 연결을 보존한다.
댓글을 캡션으로, 게시일을 사건일로, 수집 실패를 비공개로 바꾸면 잘못된 컨텍스트가 된다.
알 수 없는 정보는 비우고 확인된 비공개 계정은 지원하지 않는다.
비용이 드는 작업은 명시적으로 시작하고 같은 실행을 조회하며 실패를 자동 재수집으로 숨기지 않는다.
수집 결과가 두 추출기에 실제로 들어가고 실행 시간·청구액이 제공자 응답으로 남으면 서버 인계가 가능하다.
화면 연결·배포·머지는 이 작업의 완료 주장이 아니다.
