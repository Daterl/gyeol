# 의도

- 사진에서 관측한 사실을 순서 제안까지 전달한다는 제품 약속을 실제 모델 경로에서도 검증할 기반이 필요하다.
- 지금까지의 휴리스틱 통과는 모델의 계약 준수나 사진 이해 품질을 보여 주지 않는다.
- 키를 기다리는 동안 실패를 감추는 폴백과 오염된 캐시를 먼저 제거한다.
- 키 부재는 정상적인 휴리스틱 경로이며 사용자가 그 출처를 확인할 수 있어야 한다.
- 모델을 선택한 뒤 발생한 실패는 성공한 휴리스틱 결과로 위장하지 않는다.
- 사진 한 장씩 호출하여 아직 측정하지 않은 서버 실행시간 상한에 의존하지 않는다.
- 문자열이 달라져도 입력 사진 보존·근거 연결·계약은 유지되어야 한다.
- 실제 사진의 의미와 모델 품질은 사람이 원본과 대조하기 전까지 미검증이다.
- 키만 설정하면 기존 사진 분석 진입점에서 모델을 사용할 수 있고 실패 주입 검사가 통과하면 기반 작업을 끝낸다.
- 실제 왕복 시간·15장 비용·서버 상한은 PENDING으로 남긴다.
