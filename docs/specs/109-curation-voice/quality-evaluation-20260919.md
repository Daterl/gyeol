### 3-1. P 가 0인 이유 — 이유를 말한 뒤 이유가 아니라고 말한다

**15/15 슬롯이 같은 문장으로 끝난다: "관측 내용은 순서를 정한 근거는 아니에요."**

화면에 실제로 뜨는 8번 자리:

```
앞 사진 관측: "사람 한 명이 상체를 옆으로 돌리고 얼굴은 정면 쪽을 향하고 있다".
이 사진 관측: "사람 한 명이 벽돌 벤치에 걸터앉아 양손으로 휴대폰을 들고 아래를 내려다보고 있다".
이 사진으로 흐름을 이어가요. 관측 내용은 순서를 정한 근거는 아니에요.
```

문장의 8할이 관측 인용인데 마지막 줄이 그 인용은 이유가 아니라고 고지한다.
남는 이유는 `"흐름을 이어가요"` 뿐이고, 이 문구는 **12/15 슬롯에서 글자 그대로 동일**하다.
진짜 이유(R4 색 거리)는 접힌 근거에만 있다 — 정직하지만, 이슈 #109 가 요구한 *"자리마다 근거 한 줄"* 은 화면에 없다.

### 3-2. T 가 0인 이유 — 화법이 대체텍스트다

`관측: "…"` 인용 형식은 기계가 자기 입력을 낭독하는 화법이다. #109 가 요구한 것은
`"여기서 분위기가 한 번 바뀌어요"` 같은 사용자 언어였고, 픽셀 수치를 관측 문장으로 바꾼 것은
**용어 교체이지 화법 전환이 아니다.** 이슈 본문이 미리 경고한 실패 형태(`⚠️ 규칙 이름을 한국어로 번역하는 것으로 끝내지 마라`)와 같은 축이다.

### 3-3. F 실패 1건 — 8번 자리는 화면에서 틀린 말을 한다

`ph_08` (`c29_Dc-2OOrFBnb_07.jpg`) 원본을 900px 및 확대 크롭으로 직접 확인했다.

| 인용된 관측 | 원본 | 판정 |
|---|---|---|
| "**양손으로** 휴대폰을 들고" | 오른손 **한 손**으로 든다. 왼팔은 가죽 재킷을 걸치고 있다 | **거짓** |
| "**벽돌** 벤치에 걸터앉아" | 앉은 면은 **나무 판재**, 기단만 벽돌/붉은 타일 | 부분 거짓 |
| "아래를 내려다보고 있다" | 맞다 | 참 |

이는 **#109 코드의 결함이 아니라 상류 `PhotoAnalysis.describable_facts` 의 오류**다.
#109 는 설계상 원문을 그대로 인용하므로 거짓이 화면으로 그대로 승격된다.
E10·E11 은 이것을 못 잡는다 — 그 값은 실제로 해당 사진의 `describable_facts` 목록에 **있기 때문이다**.
부분집합 검사는 출처를 보증하지 사실성을 보증하지 않는다.

> **관측 원문을 사용자 화면에 승격시키는 설계는 vision 모델의 오류율을 그대로 제품 오류율로 만든다.**
> 실사진 15장 1벌에서 1건(6.7%)이 관측됐다. 1벌 표본이므로 비율이 아니라 **15장 중 1장**으로 읽어야 한다.

사람 큐레이터는 절대 이렇게 놓지 않는다. 각 자리는 그 와중에 `"흐름을 이어가요"` 라고 설명한다.

## 6. 발견한 코드 결함과 수정 — 없는 대비를 지어내던 인용

**결함:** `lib/curation-voice.js` `placementVoice` 는 양쪽 사진에 **서로를 구분하는 관측이 하나도 없을 때도**
각자 배열 첫 항목(`ownFacts[0]` / `adjacentFacts[0]`)을 뽑아 `앞 사진 관측: … 이 사진 관측: …` 으로 인용했다.
두 사진의 관측 집합이 같고 **배열 순서만 다르면** 화면에는 존재하지 않는 대비가 만들어진다:

```
앞 사진 관측: "흰 개가 앉아 있다". 이 사진 관측: "갈색 가방이 보인다".
… 인접 사진과 구분할 관측이 부족해 이 자리의 내용상 이유는 설명하기 어려워요.
```

두 사진 모두 개와 가방을 **둘 다** 가지고 있다. 앞 사진에 개가, 이 사진에 가방이 있다는 읽기는 거짓이고,
바로 다음 문장이 "구분할 관측이 부족하다" 고 자기모순을 낸다. 관측이 완전히 동일하면 **같은 문장을 두 번** 인용한다.

**실사진 재현:** 3장 입력 1·2번 자리. `ph_01`·`ph_02` 가 바이트 동일이라 동일 관측이 두 번 인용됐다.

**수정:** 구분하는 관측이 한쪽에도 없으면 인용 자체를 생략한다. 1개 표현식 + 조건 1개.

```js
const distinguishes = Boolean(distinctOwn || distinctOther);
const own   = distinguishes ? distinctOwn   ?? ownFacts[0]      : undefined;
const other = distinguishes ? distinctOther ?? adjacentFacts[0] : undefined;
```

**수정 전후 (실사진 3장, 1번 자리)**

| | 문장 |
|---|---|
| 전 | 지향을 넣지 않아… **다음 사진 관측: "사람 한 명이 옆을 향해 서 있다". 이 사진 관측: "사람 한 명이 옆을 향해 서 있다".** 이 사진으로 묶음을 열어요. 인접 사진과 구분할 관측이 부족해… |
| 후 | 지향을 넣지 않아… 이 사진으로 묶음을 열어요. 인접 사진과 구분할 관측이 부족해… |

**증거:** 수정 전 신규 검사 2개 **실패**(`test/placement-evidence.test.js`) → 수정 후 **통과**.
`15장 경로 출력은 한 글자도 바뀌지 않는다` (모든 슬롯에 구분 관측이 있으므로). 3장 경로만 바뀐다.

기존 검사 `15-photo fixture preserves order decisions…` 의 "모든 슬롯이 양쪽 관측을 인용한다" 단언은
**버그를 고정하고 있던 과잉 단언**이라 "인용했다면 실제 관측이어야 하고, 안 했다면 한계를 고지해야 한다" 로 바꿨다.
`docs/specs/remaining-quality/{offline-evidence.json,human-review.md}` 는 생성물이라 `scripts/remaining-quality.mjs` 로 재생성했다.
