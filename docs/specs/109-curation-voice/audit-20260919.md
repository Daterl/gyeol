## 고친 것 — 결함 1건

**첫 자리가 자기 근거에 담아 둔 비교를 문장에서 말하지 않았다.**

`placementVoice` 는 첫 자리의 인접 사진을 **다음 사진**으로 잡아 그 측정값을 `evidence` 에 넣고
모델 관측도 "다음 사진 관측: …" 으로 인용한다. 그런데 색 대비 문장만은 `previous` 를 보게 되어 있어,
첫 자리는 `previous` 가 없다는 이유로 **항상** "구분할 관측이 부족" 으로 빠졌다.
근거는 다음 사진을 가리키는데 값은 그 비교를 말하지 않는 어긋남이다.

감사 대상 15장에서 1번(ph_11, 밝기 0.808)과 2번(ph_02, 밝기 0.346)의 차이는 0.462 로
임계값 0.12 의 네 배다. 눈으로도 명백하다. 그런데 화면에는 "설명하기 어려워요" 가 떴다.

고친 뒤: **"다음 장보다 환한 화면으로 묶음을 열어요."**

- `lib/curation-voice.js` — 대비 계산의 비교 대상을 `previous` 에서 이미 계산해 둔 `adjacent`
  (첫 자리는 다음 사진, 나머지는 앞 사진)로 바꾸고, 첫 자리용 맺음말과 두 rule note 를 맞췄다.
- 회귀: `test/placement-evidence.test.js` —
  "opener describes the seam to the next photo it already cites, and abstains when there is none".
  **고치기 전 1건 실패 → 고친 뒤 통과**를 확인했다(아래 명령표).
- `docs/specs/remaining-quality/offline-evidence.json` — `order.placement_limit` note 문구가 바뀌어
  `scripts/remaining-quality.mjs` 로 재생성했다. 기록된 관측·순서·판정은 바뀌지 않았다.

## 고치지 않기로 한 것 — 판단 2건

**판단 1. `VISIBLE_STEP` 0.12 를 낮추지 않는다.**
비움 5자리 중 3자리는 차이가 0.10~0.117 로 임계값 바로 아래다. 0.10 으로 낮추면 표의 X 가 줄어든다.
그러나 그것은 **이 픽스처 한 벌에 맞춰 상수를 고르는 것**이다. 임계값은 "사람 눈에 보이는 차이"
라는 설계 판단이지 이 15장의 성적이 아니다.

**판단 2. 비움 문장을 "앞 장과 비슷한 톤으로 이어가요" 같은 말로 바꾸지 않는다.**
읽기에는 낫다. 하지만 이 순서를 정한 규칙은 R4(남은 사진 중 **색이 가장 먼** 사진)다.
"비슷해서 이어간다" 고 쓰면 **닮음이 배치 이유인 것처럼 읽힌다 — 사실이 아니다.**
차이가 설명 임계값 아래라 이 자리의 이유를 사용자 말로 옮길 수 없다는 것이 참이고,
지금 문장이 그것을 말한다. `docs/specs/remaining-quality/README.md` 의 같은 결론과 일치한다.
같은 문장 4회 반복은 이 선택의 **알려진 천장**이며, 없애려면 상수 조정이 아니라
모델 관측(`analysis_source: "vision_model"`)이 있는 입력이 필요하다 — 그때는
`order.observed_placement` 경로가 자리마다 다른 문장을 낸다.
