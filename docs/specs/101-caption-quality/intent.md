# 의도

사진을 넣고 게시까지 가려는 사용자가 초안 전체를 지우고 다시 쓰게 해서는 안 된다.
현재 감사의 캡션은 관측 사실을 빠짐없이 나열해 대체텍스트처럼 읽힌다.
P1의 편집 가능한 초안은 사진의 핵심을 고른 짧은 게시 문장이어야 한다.
사실의 수를 줄이고 말투를 바꾸되 경험·기분·장소를 만들어내지 않는다(S4).
근거 note는 문장 해설이 아니라 실제 관측으로 되돌아갈 수 있어야 한다(P2).
사진만 두어도 되는 슬롯은 그대로 허용한다(P3).
같은 실사진 15장의 전후 출력을 각각 10회 남겨 차이를 읽을 수 있게 한다.
에이전트 판정과 사람의 게시 가능 판정을 분리해 사람 검토가 남았음을 숨기지 않는다.
타이틀이 단일 사진의 광고 문구를 전체 묶음의 사실로 확대하지 않는지도 확인한다.
