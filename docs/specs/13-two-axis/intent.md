# 의도
지향과 현재를 별도로 해석하는 부담을 출력 담당자에게 넘기지 않는다.
합성된 applied_profile 하나로 캡션 길이의 차이와 적용 결과를 전달한다.
지향은 주축이며 현재는 측정된 길이를 보정하는 데만 사용한다.
간극 종류는 caption_len_gap 하나로 제한해 선택 기능의 비용을 작게 유지한다.
두 입력의 근거를 함께 전달해야 소비자가 숫자의 출처를 확인할 수 있다.
현재가 없거나 길이를 비교할 수 없으면 보정을 꾸며내지 않는다.
같은 값이면 카드를 비우고 target_only를 유지하는 것이 성공이다.
이 모듈은 문장이나 화면을 만들지 않으며 정상 폴백의 고지 키만 전달한다.
종료 기준은 계약에 맞는 합성 결과, 실제 검증 기록과 dev 대상 Draft PR이다.
