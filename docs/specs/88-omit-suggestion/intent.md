# 의도

사용자가 고른 사진을 전부 게시하도록 밀지 않고, 빼도 되는 이유가 관측된 사진만 권한다.
제품의 P3 비움 원칙을 사진에도 적용하되 선택권은 사용자에게 남긴다.
P2를 지키려면 사진의 품질을 추측하는 점수보다 실제 분석값의 출처가 먼저다.
휴리스틱 분석에서 필수 필드를 채운 기본값은 관측이 아니므로 권고를 바꾸면 안 된다.
따라서 개발 전에 같은 실사진을 한 장씩 분석해 어떤 값이 측정이고 어떤 값이 기본값인지 확인한다.
근거가 없으면 권고 0개를 정상 결과로 명시하며 모든 사진의 품질을 보증하지 않는다.
입력 사진과 출력 슬롯을 일대일로 남겨 기존 순서·캡션·편집 계약을 보존한다.
서버 결과에 권고와 추적 가능한 근거가 실리고 실사진 실행·반례 검증으로 확인되면 구현을 마친다.
화면, 자동 삭제, 사진 선별·보정, 배포, 스키마 원문 변경은 범위 밖이다.
Draft PR은 최종 완료 조건과 최신 저장소 규약에 따라 develop을 대상으로 열고 merge하지 않는다.
