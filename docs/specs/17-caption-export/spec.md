# #17 캡션·내보내기

담당 diego.yoon, 협업 enzo.cho. 기준 develop 8b7a3a7. #15 ResultScreen과 #25 store 부분 인수. Owned captions/export/copy, Shared result/input 연결 및 store generate의 mock 실행 함수 주입만 변경. 기존 generateOutput HTTP와 응답 검증을 재사용하고 새로운 서버/API 계약은 추가하지 않는다.

제목·캡션을 직접 편집하며 제안됨/비움(권장)/사용자 작성을 구분한다. 직접 지운 경우 직접 비움이라고 표시한다. 비움 근거와 그래도 채우기를 제공한다. 단일 요청은 photo_id 기준으로 해당 슬롯만 바꾸고 순서·다른 사용자 편집·근거를 보존한다. 완성률은 표시하지 않는다.

JSON과 텍스트는 현재 사용자 순서/제목/사진ID/문장/비움/근거를 동일하게 내보낸다. 전부 비워도 제목이 있으면 내보낼 수 있다. ?mock=1은 네트워크/모델 없이 현재 요청의 실제 관찰만 옮기는 deterministic QA 예시다. 다른 사진의 fixture 캡션을 붙이지 않는다. 관찰이 없는 슬롯 채우기는 설명 오류로 반환한다. 예시임을 결과 영역에 표시한다.

검증: 3상태·슬롯 채우기·재정렬/전체 비움 export·외부 호출0 테스트. 실제 브라우저 편집/다운로드/키없음 오류. 팀 밖 2명 피드백은 직접 받은 응답만 기록하며 없으면 PENDING으로 유지한다.
