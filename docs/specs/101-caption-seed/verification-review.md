# 검증 범위와 독립성

## mandela 점검

- Verifier = designer: 프롬프트 작성 에이전트가 소재 사실성도 검사했다. 모든 원본과 출력, 관측 기록을 공개해 제3자가 재검사할 수 있게 한다. 이 판정을 사람 사용성 판정으로 승격하지 않는다.
- Shared-pool bias: 이전 튜닝에서 이미 쓴 이미지 집합이며 독립 holdout이 아니다. 15개 입력 파일 중 cq_01/cq_13은 같은 SHA-256이어서 독립 이미지는 14장이다. 새 이미지 전체에 대한 일반화나 성공률을 주장하지 않는다.
- Tautology: 정규식으로 단서 형식을 검사한 것은 명사 소재가 실제로 보인다는 증거가 아니다. S4는 원본을 직접 열어 별도 판정한다.
- Frame injection / Demand characteristics: 사람 판정표의 1분 질문만으로 우월함을 입증하지 않는다. 빈 칸 조건과 단서 조건을 다른 참가자에게 배정하고 가설을 설명하지 않은 채 실제 작성 문장·시간을 받는다. 현재 모두 pending이다.

## ssotize 읽기 전용 점검

현재 단서 생성 규칙의 원천은 prompts/output/caption.md, 외부 JSON 계약의 원천은 schemas와 lib/interaction.js다. 기존 docs/specs/16-output-prompts/의 예시와 생성 실패 문구는 완성 문장을 전제로 한 과거 기록 또는 화면 문구다. 이번 작업은 이들을 대규모 변경하지 않으며 프런트 인수 시 단서가 완성 캡션으로 내보내지지 않도록 별도 확인이 필요하다. 기존 슬롯에는 단서 전용 상태가 없어 filled로 전달되는 한계가 있다.

## 검토의 한계

sip의 독립 shower는 미실행이다. 이 세션의 native spawn 도구에는 필수 agent_type 인자가 없어 설치된 역할을 지정한 독립 실행을 할 수 없으며 코디네이터의 별도 교차 리뷰가 필요하다. factchk에 해당하는 외부 세계의 성능·사용성 주장은 하지 않는다. 실행 수치는 로그, 사실성은 원본에 연결한다. 이 문서와 사양은 re0 기준으로 최종 동작과 관측 결과를 구분한다.
