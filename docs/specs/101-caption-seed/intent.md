# 쓸 거리를 건네고 저자는 사용자로 남긴다

- 사진에 없는 경험을 만들지 않으면서 완성 캡션을 쓰려던 이전 세 번의 시도는 설명문에 머물렀다.
- 이전 실측의 평균 98.6→40.5자 개선은 길이 변화이며, 사용자에게 쓸모 있다는 증거가 아니다.
- 이번 작업은 사진에서 확인한 소재를 짧게 골라, 사용자가 자기 기억과 말을 붙일 출발점을 만든다.
- 완성된 게시 문장 대신 소재 조각과 중립적인 질문을 기존 text에 담는다.
- 사용자가 1분 안에 자기 캡션을 쓸 수 있는지는 사람이 판정하며 에이전트가 통과를 대신하지 않는다.
- S4는 실제 사진과 모든 제시 소재를 대조해 확인하고, P2는 해당 사진의 관측 원문으로 추적한다.
- 비움은 성공한 결과다. 사진만 두는 자리에 단서나 질문을 억지로 추가하지 않는다.
- 타이틀·화면·스키마는 이 작업의 소유 범위가 아니다.
- 실모델 10회 이상과 다섯 검증의 원문을 남겨 develop 대상 Draft PR로 인계하면 구현 작업을 마친다.
