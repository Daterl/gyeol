관련 이슈: #101

완성 캡션 대신 관측 소재 1~2개와 고정 질문을 기존 슬롯 text에 제안하는 초안입니다. 타이틀·스키마·화면·사진 분석 경로는 수정하지 않았습니다.

## 이번 갱신: 튜닝이 아니라 측정을 고쳤습니다

앞선 세 번의 수정은 프롬프트를 고쳐 품질을 올리려는 시도였고 전부 미통과였습니다. **이번에는 프롬프트를 건드리지 않고 채점 기준을 바꿨습니다.**

기존 게이트는 소재 문구가 `describable_facts` 문자열을 **그대로 포함하는가**만 봤습니다. 그래서 `흰 털의 개`처럼 사진에 실제로 보이는 소재도 글자가 다르면 불일치로 세었고, **진짜 남은 문제가 1건인지 8건인지 구분되지 않았습니다.** 새 기준은 소재가 그 사진의 관측 사실로 **지지되는가**를 묻습니다. 느슨하게 만든 것이 아니라, 지지되지 않으면 여전히 실패이고 문자로 확정할 수 없으면 통과가 아니라 **보류**로 남겨 사람이 봅니다.

### 세 숫자 — 기존 기준과 나란히

|회차 세트|소재 수|명확한 위반|보류|통과|(기존 기준) 원문 불일치|
|---|---|---|---|---|---|
|1|362|5|44|313|197|
|2|336|3|30|303|131|
|3|276|**2**|**10**|**264**|44|
|합계|974|**10**|**84**|**880**|**372**|

기존 기준이 불일치로 세던 372건이, 새 기준에서는 명확한 위반 10건입니다. 그중 사진이 지지하지 않는 주장은 최종 회차의 `반려견` 2건이고, 나머지 8건은 `숄더백`→`가방`, `개`→`강아지`처럼 사실은 맞고 낱말만 바꾼 경우입니다(동의어 사전을 두지 않아 위반으로 떨어집니다).

### 느슨하게 만들지 않았다는 근거

사진을 직접 열고 만든 `s4-audit.json`과 최종 회차 276개 소재를 대조하면 264건이 일치하고, **사진 대조가 위반·보류로 본 것을 재채점이 통과로 올린 경우는 0건**입니다. 엇갈린 12건은 재채점이 더 보수적(9건 보류)이거나 더 엄격(`반려견` 2건)하거나, 사진을 봐야만 알 수 있어 보류로 남긴 경우(`검은 스티커` 1건)입니다.

### 재현

```
cd docs/specs/101-caption-seed
python3 rescore.py            # rescore.json / rescore.md 생성
python3 rescore.py --selftest # 판정 규칙이 뒤집히지 않았는지 14개 사례로 확인
```

**새 모델 호출 0회입니다.** 입력은 기존 `run-1.json`·`run-2.json`·`run-3.json`과 `inputs.json`뿐이며, `rescore.py`에 모델 호출 코드가 없습니다. 자체 검사는 `은색 벨트`·`초록 화분` 같은 색 귀속 오류가 통과로 올라가지 않는지, `흰 털의 개`·`진주 목걸이`가 통과하는지를 고정합니다.

## 아직 안 된 것 — merge하면 안 됩니다

- **사람 판정이 pending입니다.** 위반 10건과 보류 43종의 O/X 칸을 비워 두었고, 에이전트 의견은 별도 열에 적었습니다. 사람 판정을 대신하지 않았습니다.
- 자연어 회차의 비움은 7·6·8·0개로 8/15 이상 유지를 충족하지 못했습니다. 이번 범위는 측정이라 이 회귀는 그대로 남아 있습니다.
- 재채점은 **사진을 보지 않습니다.** 관측 사실 자체가 틀렸다면 재채점도 같이 틀립니다. 동의어·상위어를 모르고, 핵심어를 마지막 어절로 단순히 잡으며, 색 수식어 귀속을 어순 사슬로만 봅니다. 한계는 `rescore.md` 마지막 절에 적었습니다.
- 기존 15개 파일 중 두 파일이 동일 SHA-256이라 독립 이미지는 14장입니다. 새 이미지 일반화 증거가 아닙니다.
- Node v22.22.3에서 검사했고 레포 요구 Node 24.x 환경은 미검증입니다. 독립 교차 리뷰와 화면/내보내기의 단서 취급도 미검증입니다.
