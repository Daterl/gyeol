## 최종 생성 프롬프트

```text
Use case: stylized-concept. Create ONE polished raster art-direction contact sheet for an original Korean photo-curation app GYEOL. The user wants genuinely funky, cute, high-quality IMAGE mascots that fit a calm editorial photo-results screen. This is exploratory concept art, NOT a website screenshot, NOT a logo. Warm ivory paper background #F6F3ED. Exactly two separate original character concepts shown in a spacious 2-column composition; each column has one large hero pose above two smaller expressive poses. LEFT: a quirky little folded photographic-paper creature, softly irregular ivory rectangular body with a curled corner, dark forest-green tiny limbs, expressive asymmetrical dark oval eyes and restrained mischievous smile, carrying a tiny blank photo print. RIGHT: an adorable tactile rounded lime-green pebble/paper-weight creature with slightly lopsided sculptural silhouette and expressive eyes, helping lean two tiny ivory photo prints into an orderly stack. Make the two concepts distinctly different, cohesive and friendly rather than babyish. Premium handmade matte paper/clay illustration rendered as a 2D bitmap, refined soft studio light, subtle realistic texture, crisp intentional silhouette, editorial toy art, highly art-directed, no cheap generic stock blobs. Forest green anchors, small funky lime and lilac accents; very small coral details only. The smaller poses communicate thoughtful sorting and a small satisfied completion, not exaggerated celebration. Lots of clean breathing room so each creature is legible at thumbnail size; no overlapping of the two concepts. Add just one tiny original sticker-like accent near each group, subordinate to the mascots. No text, letters, numbers, UI, badges, progress bars, logos, watermarks, real people, recognizable copyrighted characters, or fabricated photo scenes. Do not imitate an existing reference mascot. The final deliverable is one high-resolution comparison board image; no animation and no code.
```
