## 제작 이력

내장 imagegen으로 생성, 원본 출처는 로컬 생성 작업01a0adf6-05bf-7b30-a8f8-ceec89a1d328. default df0e7233-8158-404f-8577-cca3cd90c72b / working72356095-471b-4fa5-844a-040d9d31e2f7 / complete c6821a88-1a2a-42d1-b124-6c2835d06ec7 / recovery db15b5f6-7e22-4bb4-b2b5-918435d478e9. 비밀값이 아닌 제작 출처 식별자다.

프롬프트 공통: 왼쪽 종이 친구의 아이보리 섬유, 오른쪽 상단 접힘, 비대칭 초록 눈, 장갑/신발, 부드러운 좌상단 조명을 유지. 텍스트/배경/체커보드/바닥/외부 그림자 없이 독립 투명 PNG. 상태별 소품만 한 장/두 장/안고 있기/안심 손짓으로 변경. 결과를 앱에서 성공 신호로 오용하지 않는다.

## 확인 및 인계

- RGBA alpha0~255 및 가장자리 투명 확인. 첫 기계 검사에서 희미한 반투명 픽셀 때문에 전체 alpha bounding box가 넓게 잡혔다. 원본을 자르거나 threshold 처리하지 않고 alpha>128의 가시 경계와 실제 표시를 함께 확인했다.
- CUA Chrome에서 네 상태 ×64/128/256px, 종이/흰색/초록 배경 모두 확인. 20개 이미지 로드 성공. 작은 얼굴·접힌 모서리·손/사진이 구분되고 표시 크기에서 불투명 사각 배경, 잘림, 두드러진 halo 없음. 미세 섬유 경계는 원본에 남는다.
- 이미지 하나만 장식으로 사용한다. 별도 스티커는 같은 내용을 반복하므로 만들지 않는다(최대2개 중1개). 사진 위 합성·CSS/SVG/Canvas 캐릭터·emoji·3D 런타임 없음.
- #36: 320px 숨김, 모바일64px/데스크톱96px 권장. width/height 예약, alt="", 텍스트로 상태 제공. 상태 파일을 map에서 하나만 선택하고 네 상태를 미리 로드하지 않는다. 이미지 실패가 CTA나 안내를 지우면 안 된다.
- 표정만으로 상태를 설명하지 않는다. recovery는 default와 비슷한 차분한 얼굴이며 오류/복구 행동은 HTML이 원천이다.
- 제품 코드/의존성 변경 없음. 앱 기능 테스트는 해당없음, 실제 화면 배치·전송량·상태 연결은 #36.

Verdict: 로컬 에셋 제작·크기 QA PASS. Preview 파일 확인 후 develop 통합. 최종 서비스 반영 완료를 뜻하지 않는다.
